Phase 4: hybrid feature selection (Pearson + ANOVA + chi2 + GA)

selection.py
- pearson_prune: greedy collinearity removal. Walks the ORIGINAL column
  order and compares each candidate only against already-accepted features,
  so the outcome cannot depend on set/dict iteration order.
- univariate_scores: ANOVA F-test + chi-square (on min-max scaled input).
  Chi-square is kept alongside ANOVA because a monotonic-only filter is
  blind to U-shaped dependence.
- shortlist_by_rank: blends the two measures by RANK, not raw score.
  F-statistics and chi2 have incomparable magnitudes, so averaging raw
  values would let ANOVA dominate purely by scale.

genetic.py
- Bit-string GA over the shortlist. Fitness = 0.85*PR_AUC - 0.15*parsimony,
  matching the project pseudocode. Elitism + tournament selection + uniform
  crossover + bit-flip mutation. PR-AUC over ROC-AUC because at a 1.23%
  attack rate ROC-AUC is dominated by the benign majority.

Validated on all 451,380 real rows (74 candidates -> 30 features, 41%):
- Pearson dropped 30 collinear columns in 3.4s. Detected pairs are exactly
  the known CICIDS-2017 redundancies, e.g. SYN Flag Count ~ Fwd PSH Flags
  at |r| = 1.0000, and Avg Fwd Segment Size ~ Fwd Packet Length Mean.
- The SFE and domain features genuinely earn their place: SFE_GMM_Resp_1
  (F=1350) and SFE_GMM_Resp_2 (F=1312) rank 4th and 5th overall, above
  nearly every raw CICIDS column. Byte_Entropy ranks 6th (F=1086).
  6 of 7 derived features survive into the final top-30.

Fixed a serious bug caught only by real data: SFETransformer preserved the
input index, so pd.concat(axis=1) outer-joined on duplicate labels left by
.iloc[train_idx] and silently grew 315,972 rows to 410,780. The embedding
now returns a fresh RangeIndex; added a regression test for it.
