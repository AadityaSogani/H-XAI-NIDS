Phase 5a: Next.js 16 scaffold + design system + landing page

- Next.js 16.4 / React 19.3 / Tailwind v4 / Recharts 3.10 scaffolded.
- globals.css: dark SOC design tokens (canvas/surface/ink), a fixed severity
  ramp shared by every chart and badge, glass .panel, aurora glow, grid
  backdrop, pulse/sweep animations that respect prefers-reduced-motion.
- lib/types.ts + lib/api.ts: typed client. A 503 (API up, no model) is kept
  distinct from a network error (API down) because they need different fixes.
- components/ui.tsx: Panel, PageHeader, VerdictBadge, StatusDot,
  ContributionBar, buttons, ErrorBanner, Nav.
- app/page.tsx: hero, live metrics fetched from /metrics (never hard-coded),
  8-stage pipeline grid, and an explicit known-limitations panel.

next.config.ts: cacheComponents disabled. Next 16 enables it by default, but
it conflicts with `export const dynamic` and would cache live detection
results - a stale no-threats-found on a security dashboard is the worst
possible failure mode.

Verified: npm run build succeeds, TypeScript passes, route / is dynamic.
