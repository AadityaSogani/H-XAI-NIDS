Phase 6: FastAPI backend for the trained hierarchy

app/config.py      Settings from env, all with working defaults.
app/schemas.py     Pydantic contracts. FlowFeatures uses extra="allow" because
                   the CICIDS feature set is wide and the selected subset may
                   change on retrain; requiring every column up front would
                   break the client each time. align() ignores extras.
app/model_store.py Loads the artifact ONCE during lifespan startup, not per
                   request - deserialising a 200-tree forest on every call would
                   dominate latency. If no artifact exists the app still boots
                   and reports model_loaded=false, so /health tells an operator
                   exactly what is wrong instead of the container crashing.
app/routes.py      /health /predict /predict/explain /predict/batch
                   /predict/upload /metrics /features.
                   A malformed feature dict returns 400 (caller error); a missing
                   model returns 503 (server state). SHAP failures never lose an
                   alert - explanations are advisory and degrade to empty.
app/smoke_test.py  Live end-to-end test against the real artifact.

Verified working against the trained model:

  GET  /metrics         -> 200  PR-AUC 0.9714
